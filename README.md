# 📝 BLOG DO MURILO

> Um blog pessoal desenvolvido para compartilhar minhas experiências, aprendizados e pensamentos sobre curiosidades do mundo alheio

🎨 

## 🚀 Sobre o Projeto

Este projeto é o meu canto pessoal na web. O objetivo principal deste blog é documentar a minha jornada de aprendizagem sobre curiosidades, criando artigos práticos e reflexões sobre os desafios que enfrento no dia a dia.

Aqui você encontrará textos sobre:
- 💻 Desenvolvimento Web e código limpo.
- 🛠️ Tutoriais passo a passo de ferramentas que utilizo.
- 🧘‍♂️ Opiniões e vivências pessoais no mercado de trabalho.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

*Aulas do Alura 
*Ajuda do maravilhoso Marcos Felix

## ✨ Funcionalidades

- **Modo Escuro / Claro:** Conforto visual para leitura em qualquer ambiente.
- **Design Responsivo:** Navegação otimizada para celulares, tablets e desktops.
- **Filtro por Categorias:** Organização rápida dos posts por tags de interesse.
- **Busca Rápida:** Encontre artigos facilmente através de palavras-chave.
